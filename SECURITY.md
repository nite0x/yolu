# Security policy

Yolu manages local repositories, working directories and development sessions. Include the affected version and source commit when reporting a problem. The project does not currently promise a long-term support period or a fixed response time.

Do not disclose exploit details, tokens, `service.json`, private repository contents or complete conversations in a public issue.

Use private vulnerability reporting on the repository's [Security page](https://github.com/nite0x/yolu/security) when it is enabled. If no private reporting entry is available, open a public contact request without sensitive details and wait for a private channel before sharing reproduction material.
