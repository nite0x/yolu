# Application capture provenance

The gallery shows the browser UI served by a temporary Yolu backend at 1280 × 720 with the Yolu Mint palette. It uses temporary Git repositories and a deterministic Codex protocol fixture. It includes no real account or conversation data.

- `assets/conversation.jpg` shows a storefront conversation with two linked directories and their actual read and write access states from the test profile.
- `assets/changes.jpg` shows the shared file pane with a real working-tree diff from the sample checkout.
- `assets/terminal.jpg` shows the integrated shell and the output of `git status --short --branch` in that checkout.
